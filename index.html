The Catalan sequence

The nth Catalan number counts many recursive structures. Use the calculator, then inspect its direct formula and recurrence.

Calculate a Catalan number

Enter n as a non-negative integer. The calculator uses exact integer arithmetic.

Two useful formulas

Cₙ = 1/(n + 1) · (2n choose n)
Cₙ = (2n)! / [n!(n + 1)!]

The recurrence begins with C₀ = 1 and adds products of smaller Catalan numbers.

Cₙ = Σ Cᵢ Cₙ₋₁₋ᵢ

The sum runs from i = 0 to n − 1.

02 / Application

How many ordered binary trees?

A binary tree is an empty tree or a root with a left subtree and a right subtree. Swapping left and right subtrees can create a different ordered shape.

Explore tree shapes

Recurrence in action

Count by choosing the root's subtrees

Cₙ = Σ Cᵢ Cₙ₋₁₋ᵢ

For every possible size of the left subtree, multiply the number of left shapes by the number of right shapes, then add the results.

This counts shapes, not all possible labelings of the nodes. The empty tree is counted as C₀ = 1.

03 / Application

Polygon triangulation

A triangulation divides a convex polygon into triangles using non-crossing diagonals. A convex polygon with m vertices has Cₘ₋₂ triangulations.

Build a triangulation

Why Cₘ₋₂?

T(m) = Cₘ₋₂

Fix one edge of the polygon. Every triangulation contains exactly one triangle attached to that edge. Choosing the third vertex splits the remaining polygon into smaller parts, leading to the Catalan recurrence.

Reference notes

Definitions, examples, and interpretation

Use this section to review ideas and then explain them in your own words in the assignment book.

Definition

The Catalan numbers are a sequence of non-negative integers commonly used to count certain recursively defined structures.

Cₙ = (2n)! / [n!(n + 1)!]

Worked example: C₃

C₃ = 6! / (3! × 4!) = 720 / 144 = 5.

Applications at a glance

Ordered binary trees
Cₙ shapes with n nodes.
Convex polygon triangulation
Cₘ₋₂ triangulations for m vertices.
Balanced parentheses
Cₙ valid sequences of n pairs.
Expression parenthesization
Cₙ₋₁ ways to fully parenthesize n operands in order.

Conclusion

Catalan numbers connect different counting problems through a shared recurrence. Calculating values and exploring the corresponding structures helps reveal why they arise in trees, polygons, and balanced sequences.
